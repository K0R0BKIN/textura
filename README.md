# Textura

Dictionary application in early development.

## Tech stack

- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS 4
- **UI:** shadcn + Base UI
- **Data:** [Wiktionary](https://en.wiktionary.org/) via [Kaikki.org](https://kaikki.org/), licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- **Database:** Neon Postgres + Drizzle ORM
- **Search:** Algolia Search and Autocomplete

## Setup

```bash
pnpm setup
pnpm dev
```
